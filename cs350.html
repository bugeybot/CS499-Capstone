Algorithms and Data Structures Enhancement

My artifact for the algorithms and data structures category is a Python-based text adventure game originally developed in IT 145. The initial version presented a linear gameplay structure, with basic item collection and a fixed win condition. To better demonstrate my growth in algorithmic design and logical complexity, I significantly expanded this project through puzzle-based gameplay and a dynamic save system.

The first enhancement was the addition of logical puzzles that gated item access. For example, a riddle posed by a statue must be answered to obtain armor, and a logic puzzle involving contradictory clues is required to retrieve a gemstone from one of three basement boxes. These puzzles are solved using truth-value tracking and conditional branching, adding cognitive depth and requiring players to engage in reasoning rather than simple exploration.

Another major enhancement involved expanding the command parser. The original parser recognized only basic "go" and "take" commands. I broadened the input system to understand synonyms, such as "look", "interact", and "use", while maintaining clear syntax handling. This required the use of dictionaries and parsing logic to map varied commands into core actions, reflecting mastery of control flow and data mapping techniques.

To increase replayability, I randomized critical game variables such as safe codes and puzzle solutions. The birthday clue leading to a code-based safe and the gem location in the logic puzzle are now procedurally generated at runtime and encoded in the save system.

Finally, I implemented JSON-based save/load functionality, giving players the ability to preserve progress. The save file includes inventory state, room-specific changes, and dynamic values, demonstrating use of serialization and deserialization of complex Python objects.

This enhanced artifact showcases recursive logic, dictionary-driven command interpretation, procedural content generation, and data persistence. These are key algorithmic and data structure skills that demonstrate competency in designing systems that go beyond surface-level programming.
