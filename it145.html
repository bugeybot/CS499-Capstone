Software Design and Engineering Enhancement

For the software engineering category, I selected my embedded systems project from CS 350. Originally, this program flashed an LED in a fixed SOS or OK pattern using a state machine in C. While functional, the original design was rigid and lacked user flexibility, offering no means to personalize behavior.

To showcase deeper understanding of embedded systems and user-centered design, I introduced several enhancements. First, I added support for custom Morse code messages. Users can now input any string of text to be encoded and flashed as Morse code. This required the creation of an ASCII-to-Morse encoding system, a more robust state machine, and memory-safe handling of user input on constrained hardware.

Second, I developed a console simulation mode to support testing without requiring deployment to hardware. This mode prints LED states and message patterns in real time to the console, reflecting a strong grasp of embedded debugging strategies.

Finally, I implemented adjustable timing controls for dot and dash lengths, giving users a way to modify message speed on the fly. This required parameterization of timer intervals and careful interrupt management to ensure consistency between ticks.

These enhancements demonstrate mastery of real-time systems, embedded interface development, and user-configurable design. They fulfill course outcomes around technical communication, algorithmic design, and value-driven software engineering. Most importantly, they turn a basic program into a flexible and extensible tool that feels like a real product.
