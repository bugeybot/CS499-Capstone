Professional Self-Assessment

Throughout my journey in the Computer Science program at Southern New Hampshire University, I have worked hard to develop both foundational and advanced skills that I am proud to showcase here. This ePortfolio represents not just a culmination of coursework, but a personal testament to my growth in real-world programming, design, algorithmic thinking, and secure database implementation.

Collaboration has been a major component of my development. I've worked in simulated professional settings to coordinate across roles and complete milestone-driven development tasks. Whether refining code with instructor feedback or updating documentation in a shared repository, I've gained an appreciation for team communication and version control strategies using Git.

Communication with stakeholders was reinforced in multiple projects, particularly those requiring presentations or interactive dashboards. I learned to tailor my technical explanations for non-technical audiences and to justify design decisions that impact user experience and data security. My work in the CS 340 dashboard exemplifies this, as I created intuitive interfaces supported by secure database operations.

In algorithmic thinking, I demonstrated mastery by creating more complex and dynamic decision trees in my enhanced IT 145 artifact. There, I expanded a text-based game with puzzle logic and state persistence, ensuring replayability while maintaining readability and modularity in my Python code.

My software engineering skillset was especially sharpened through embedded systems development in CS 350. I rewrote LED timing logic using state machines and implemented custom timing configuration via hardware interrupts. I added user configurability to a pre-structured firmware project, demonstrating both deep understanding of real-time constraints and interface design.

Security and design trade-offs were pivotal in my database work, especially in CS 340. I introduced role-based user systems and tailored front-end visibility to those roles. The backend MongoDB functionality was extended to check user types before granting CRUD operations, ensuring adherence to the principle of least privilege. These enhancements reflect industry best practices in full-stack security and data stewardship.

Each artifact featured in this portfolio—whether enhanced for software design, algorithm complexity, or database interaction—has pushed me further toward industry readiness. They represent measurable progress across the five core CS program outcomes. I invite you to explore the specific enhancements that follow and witness how they reflect not only the skills I've acquired but the developer I've become.
