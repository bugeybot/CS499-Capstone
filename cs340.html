Database Enhancement

My database-focused artifact originates from CS 340, where I developed a dashboard using Dash and MongoDB to visualize animal shelter records. The original artifact allowed users to browse a database of adoptable animals and filter results based on various criteria, displaying them in a searchable table, interactive map, and pie chart.

For my enhancement, I focused on introducing secure user authentication and role-based access control. This significantly improves the professionalism and security of the application, aligning it with real-world production practices. I implemented a simple login system that assigns user roles—basic or admin—on authentication.

The dashboard now adapts its interface based on user permissions. Admin users are granted additional UI components that allow them to create, update, and delete animal records directly from the dashboard. This dynamic front-end rendering is driven by user session data and showcases my ability to link database behavior to user roles in a responsive design.

In the backend, I expanded the CRUD interface of the AnimalShelter class to validate user roles before allowing write operations. This includes verification for data integrity and exception handling for unauthorized attempts. By segregating database privileges, I reinforced the principle of least privilege in application design.

These enhancements demonstrate both technical knowledge and awareness of software security concepts. I used conditional rendering logic, Python decorators, and role-aware MongoDB queries to meet the course outcomes related to database design, secure development, and usability.

This project is now not only informative and interactive—it is secure and scalable. It presents a realistic example of how a database-driven application can respond to diverse users while protecting sensitive operations.
